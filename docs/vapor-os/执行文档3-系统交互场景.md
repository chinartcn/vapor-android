# Vapor OS 演示 · 执行文档 3：系统交互场景

> 面向执行者的可并行实施文档。本系列共四份，**文件所有权零重叠，可同时开工**。
> 本份负责 Vapor OS 的**系统级交互场景**：下拉通知中心、Quick Settings 面板、锁屏、最近任务（多任务）四张场景，以及从状态栏/手势条触发这些场景的接线与路由。
> 复用已落地的 `vos.chrome`（`MdNotificationCenter`/`MdQuickSettings`/`MdHeadsUp`）、`vos.launcher`（`MdLockScreen`/`MdRecents`/`MdGestureNav`）。禁止硬编码主题色。

## 3. 场景规格

### 3.1 `ShadeScreen` — 下拉通知中心 + Quick Settings

| prop | 默认 | 说明 |
|---|---|---|
| `notifications` | `[]` | 通知数据（来自文档 4 示例数据） |
| `tiles` | `[]` | QS 瓷砖 `[{label, icon, on, on_toggle}]` |
| `expanded` | `False` | False=半展开（只 QS 一行 + 通知），True=全展开（QS 网格） |
| `brightness` | `None` | 亮度条 0..1 |
| `on_dismiss` / `on_tile` / `on_close` | `None` | 回调 |

- **结构**：顶部状态栏 → QS 区（`MdQuickSettings`）→ 亮度条 → 通知列表（`MdNotificationCenter`）→ 底部"清除全部"。
- **下拉手势**：从顶部状态栏区域下拉，`pull` 进度 0..1 驱动面板下移 + scrim 透明度；超过阈值展开为 `expanded=True`。回弹用 expressive spring。
- **通知滑除**：直接复用 `MdNotification` 的滑除（文档2 已实现 tap/swipe 区分），`on_dismiss` 回调把 id 交给调用方。
- **关闭**：上滑面板或点击 scrim → `on_close` 回调。

### 3.2 `LockScreenScene` — 锁屏场景

| prop | 默认 | 说明 |
|---|---|---|
| `time` / `date` | `""` | 时钟/日期文本 |
| `notifications` | `[]` | 锁屏通知预览 |
| `locked` | `True` | 锁定态 |
| `on_unlock` | `None` | 解锁回调（路由归调用方） |

- 直接嵌 `MdLockScreen`（文档3 已实现上滑解锁、中文 emphasized 大字时钟）。
- 解锁成功只发 `on_unlock`，不直接切页——由 Shell/调用方决定解锁后落到主屏还是上次的 app。

### 3.3 `RecentsScreen` — 最近任务（多任务）

| prop | 默认 | 说明 |
|---|---|---|
| `tasks` | `[]` | `[{id, title, preview, on_select, on_dismiss}]` |
| `on_clear` | `None` | 清除全部回调 |

- 直接嵌 `MdRecents`（文档3 已实现卡片栈、横滑切换、上滑滑除）。
- 选中卡片只发 `on_select(id)`，切页由调用方执行。

### 3.4 `SystemGestures` — 手势接线层（私有 helper）

- 把 `MdGestureNav` 的三个回调（back/home/recents）接到场景切换：
  - `on_home` → 调用 `props["on_home"]()`（回主屏，调用方处理）
  - `on_recents` → 本场景内切到 `RecentsScreen` 或回调
  - `on_back` → `props["on_back"]()`（调用方决定返回行为）
- 本 helper 是所有场景共用的手势条，避免每个场景重复创建。

## 4. 实现要点与坑

1. **场景都是 Component 子类**：每个场景 `name` 唯一（`ShadeScreen`/`LockScreenScene`/`RecentsScreen`），有 `props`/`build`，可独立 instantiate 和测试。
2. **路由全回调**：解锁/选卡/关面板/切页都只发回调（`on_unlock`/`on_select`/`on_close`/`on_home`...），本份**不调用 `navigate()`/`go_back()`**——遵守"路由归调用方"。
3. **scrim 取色**：遮罩用 `with_alpha(current_theme().role("onSurface"), 0.2)`；主题切换后 effect 重跑更新。
4. **下拉与滑除手势不冲突**：Shade 的下拉从上边缘区域触发；通知条目的横向滑除在 `MdNotification` 内部处理——两者作用方向不同（垂直 vs 水平），无需额外仲裁。
5. **reduced_motion**：下拉/展开/卡片切换在减弱动效下瞬时到终态。
6. **中文**：场景内所有文本 `type_style(..., lang="zh")`。

## 5. 验收测试（`test_vapor_os_system.py`）

- `test_shade_renders`：给定通知/瓷砖数据，`ShadeScreen` instantiate 后含 QS 与通知列表节点。
- `test_pull_threshold`：下拉位移小 → 回弹不展开；大 → `expanded=True`（或触发 `on_open`）。
- `test_notification_dismiss_delegates`：通知滑除触发 `on_dismiss`，不改 props。
- `test_lock_unlock_callback`：上滑超阈值触发 `on_unlock`，且未直接 `navigate`（mock 断言）。
- `test_recents_select_callback`：选中卡片触发 `on_select(id)`，不直接切页。
- `test_gesture_wiring`：`MdGestureNav` 三回调分别转发到 `on_home`/`on_back`/`on_recents`。
- `test_reduced_motion_snap`：`VAPOR_REDUCED_MOTION=1` 时所有场景切换瞬时终态。
- `test_no_hardcoded_color`：`system.py` 无主题色字面量。
